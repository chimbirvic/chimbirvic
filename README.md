## Избранный проект / Featured Project

### [MAXMERCH — A/B-тест экрана приоритизации задач](https://github.com/chimbirvic/Practice_projects/tree/main/Jupyter_Notebook_projects/maxmerch_ab_test)

Портфолио-кейс с синтетическими данными. Полный цикл A/B-теста: проверка данных и рандомизации, расчёт выборки, ITT-анализ на уровне мерчендайзера и оценка защитных метрик. Эффект +0,54 п.п. статистически значим, но ниже бизнес-порога +1 п.п.; рекомендация — не масштабировать без дополнительного обоснования экономики.

A portfolio case using synthetic data. End-to-end A/B test analysis, including data quality, randomization checks, sample size, user-level ITT, and guardrail metrics. The estimated effect was +0.54 pp, statistically significant but below the +1 pp business threshold.
